# Ключевые уточнения (обязательны)

1. **Вся колонка фильтров** (sidebar), включая область с логотипом/названием, имеет **серый фон, такой же как фон страницы**.
2. Клик по **логотипу + названию** вверху sidebar ведёт на **главную** (`/`).
3. Заголовок **«Выберите из 500+ проектов»** сделать **заметно жирнее**.
4. Тексты поверх hero-визуалов (3 картинки) оформить **в стиле первой страницы**, иначе не читаются: подложка/градиент/blur-плашка + белый текст.
5. Отступы между карточками в матрице сделать **шире** (`gap` больше).
6. Геолокация (город) в карточке — **ссылка на Google Maps** (новая вкладка).
7. В sidebar **верх (логотип/название) не прокручивается**, прокручивается **только область фильтров**.
8. На основном экране **прокручивается только матрица результатов** (grid). Верхняя белая область и строка управления остаются на месте.
9. В фильтрах (checkbox-группах) допускается **мультивыбор**: можно выбрать несколько значений одновременно.
10. Логика чекбокса **«Все»** в каждой группе:

* при выборе «Все» → **выделяются все** значения этой группы (включая/исключая «Все» — выбери консистентно, но UI должен показывать “все выбраны”)
* при снятии «Все» → **снимаются все** значения в группе
* если пользователь вручную выбрал все отдельные значения → «Все» автоматически становится активным (желательно)

11. Высота верхней белой области (Hero-top) — **1/4 высоты экрана** (не 1/3).
12. Высоту/плотность блока **«Подобрали для вас»** и **полосы управления (chips + sort)** уменьшить **в 1.5 раза** относительно предыдущего варианта (меньше высота, меньше паддинги, чуть меньше шрифт).

## 1) Sidebar filters (левая панель)

* Ширина: `w-1/5` или `basis-1/5`.
* Фон: **серый как у страницы**.
* Внутри две зоны:

  1. **Sticky header** (не скроллится):

     * логотип + «вКвартирах»
     * кликабельно → `Link` на `/`
  2. **Scrollable filters body**:

     * вертикальные секции фильтров (accordion)
     * скролл только здесь (`overflow-y-auto`, `min-h-0`, `flex-1`)

### Фильтры (checkbox-группы с мультивыбором)

Группы:

1. Тип помещения: Все, Квартира-студия, Квартира, Коттедж, Пентхаус
2. Комнат: Все, 1–7
3. Стоимость: диапазонный слайдер min/max 0–1 000 000 ₽
4. Стиль: Все + стили (мультивыбор)
5. Дизайнер: Все + дизайнеры (мультивыбор)
6. Другое: Все + флаги (мультивыбор)

**Обязательное поведение “Все”:**

* `onCheck(Все=true)` → set выбранных значений = все значения группы (кроме “Все” можно хранить отдельно)
* `onCheck(Все=false)` → set выбранных значений = пусто
* Если set выбранных значений == все значения группы → “Все” отмечен
* Если set пустой → “Все” не отмечен (или группа в состоянии “нет фильтра” — но тогда chips должны корректно это отражать)

## 2) Основной экран (правая область)

### 2.1 Верхняя белая зона (Hero-top) — **1/4 высоты экрана**

* Высота: примерно `h-[25vh]` (или `basis-1/4` в flex-колонке)
* Фон белый
* Левый нижний угол скруглён (~40px)
* **НЕ прокручивается**

Состав:

1. Верхняя полоска (≈64px):

* слева меню: Каталог / Дизайнерам / Бизнесу
* справа иконки: поиск, уведомления, коммерческие предложения, аватар
* тонкие вертикальные разделители между иконками
* тонкая серая линия снизу

2. Заголовок (жирный):

* «Выберите из 500+ проектов» — **font-bold / 700+**

3. Hero-лента из 3 изображений:

* `public/pic/home_page_1.png`
* `public/pic/home_page_2.png`
* `public/pic/home_page_3.png`
* горизонтально вплотную, без gap
* ограничение по высоте под 1/4 экрана (не съедает заголовок и верхнюю полоску)
* отступы до нижнего/левого/правого края белого блока — **32px**
* поверх изображений — 3 тезиса, оформленные “как на первой странице” (подложка/градиент/blur для читаемости)

### 2.2 Нижняя зона (каталог)

В этой зоне **не скроллится весь контейнер** — только grid.

Сверху вниз:

1. Заголовок: **«Подобрали для вас»**

   * уменьшить “в 1.5 раза”: меньше line-height, меньше padding/margin, чуть меньше font-size (пример: было text-xl → сделать ближе к text-base/large)

   * тоже уменьшить “в 1.5 раза”: компактнее по высоте, меньше вертикальные паддинги, аккуратные chips

3. Ниже: **Scrollable grid** результатов

   * `overflow-y-auto`, `min-h-0`, `flex-1`
