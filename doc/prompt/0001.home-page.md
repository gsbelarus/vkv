## Project: «вКвартирах» / Home Page

Ты — **senior frontend engineer и продуктовый дизайнер**, работающий в режиме **vibe coding**.
Ты сразу пишешь **production-ready код**, опираясь на визуальный вайб, UX и продуктовую логику, а не на формальное ТЗ.

Ты работаешь **строго в рамках Next.js App Router**.

## Технологический стек (обязателен)

* **Next.js 16+**
* **App Router**
* `app/` directory
* Server Components по умолчанию
* Client Components — только при необходимости
* CSS: **Tailwind CSS**

## Контекст продукта

**Приложение:** вКвартирах
**Сегмент:** B2C
**ЦА:** покупатели дизайн-проектов квартир (готовые проекты, кастомизация, реализация).

Продукт:

* продаёт интерьерные дизайн-проекты;
* позволяет кастомизировать под квартиру;
* ведёт пользователя от выбора → покупке → реализации.

## Текущая задача

Реализовать **главную страницу приложения** (`/`).

Главная страница:

* это **вход в продукт**, а не маркетинговый лендинг;
* визуально ощущается как **премиальный интерьерный каталог**;
* ведёт пользователя в каталог проектов.

## Входные ассеты (использовать строго)

### Аватар пользователя

```
public/pic/user.png
```

### Hero-визуал (единая композиция из 3 изображений)

```
public/pic/home_page_1.png
public/pic/home_page_2.png
public/pic/home_page_3.png
```

⚠️ Это **один визуальный блок**, а не три карточки. Три изображения следует разместить горизонтально, одно за другим, без пробелов и отступов, образуя единый арт-объект. Правый нижний угол всей композиции скруглён с радиусом 40px.

## Обязательная структура страницы

### `/app/page.tsx`

Главная страница. Составные части:

* Заголовок
* Основное содержимое страницы 
* Подвал 

### Заголовок 

Заголовок должен быть сплошной белой полосой высотой 64px, 
отделенной тонкой серой линией снизу. 

На заголовке располагаем по горизонтали:

* слева: логотип и название
* за ним, с отступом, основные ссылки: Каталог, Дизайнера, Бизнесу.
* справа: пиктограммки (пиктограммки разделены небольшими тонкими вертикальными линиями): 
    * поиска, 
    * уведомлений, 
    * коммерческих предложений, 
    * аватар пользователя (`user.png`).

### Основное содержимое страницы

Слева направо (на десктопе):

* **композитный визуал из 3 изображений**, собранных в единую арт-композицию. Занимает примерно 60-65% ширины экрана;
* справа от визуала — вертикальный блок с двумя колонками, каждая по 50% ширины блока. Высота блока равна высоте визуала.
  * первая колонка. содержит по вертикали:
      * крупный акцентный год (например: `2026`);
      * H1: **Каталог интерьеров**
      * подзаголовок: *Дизайн-проект вашей квартиры*;
      * вертикальный список из пиктограммок социальных сетей (Facebook, Instagram, TikTok, Pinterest). 
      * по правой границе колонки — тонкая вертикальная линия, визуально отделяющая колонку от следующей колонки.
  * вторая колонка. содержит по горизонтали, выравнивание по центру:
      * Надпись "Подробнее" развернутую на -90 градусов. Т.е. текст расположен вертикально, читается снизу вверх. 
      * Сплошной треугольник смотрящий вправо (стрелка).
      * Полупрозрачная надпись "ИНТЕРЬЕРЫ". Развернута на -90 градусов. Т.е. текст расположен вертикально, читается снизу вверх. Шрифт крупный, так чтобы надпись по высоте заполняла всю колонку. Использовать основной цвет из палитры продукта.
  
### Подвал

* Примыкает к низу страницы без отступов.
* высота подвала 1/5 от высоты экрана. 
* В левой части вертикальное меню с основными ссылками (Каталог, Дизайнера, Бизнесу). Левая граница на одном уровне с левой границей логотипа в заголовке. Шрифт жирный, крупнее чем в заголовке. Серый.
* В правой части, по ширине второй колонки основного содержимого страницы, на инвертном фоне (тёмный фон, светлый текст, используй цвета из палитры продукта):
    * контрастный терракотово-красный фон;
    * Надпись "Узнайте, что сейчас в моде".
    * Стрелка или визуальный call-to-action.
    * Левый верхний и левый нижний углы блока скруглены радиусом 28px.
